          距离校准（净距 = 原始 − 安装偏置）
            —
            
          
          

            

              雷达装在车体内部，量到的是「雷达到障碍」；减掉安装偏置才是「车壳到障碍」的净距。
              校准方法：把箱子（或一堵墙）贴住哪一侧，就点哪一侧的「贴住校准」——读到多少就记成那一侧的偏置。
              之后上面显示的距离、以及避障阈值，都按净距算（所以「贴住」＝净距 0）。偏置会存盘，重启也在。

          雷达扫描图（实时俯视）
            
          
          

            

              
              
              
              

              展开本块并停留在遥控页才会持续刷新
            

            
            

              原点=雷达自己（0°=车头，+90°=左）；红圈=盲区(range_min)，比它更近的东西雷达一个点都不回；
              点色 红<0.5m / 橙<1m / 黄绿<2m / 青灰=更远；
              两根黄线之间就是避障判据用的扇区；超出视场的点画在最外圈（暗灰）。

          直行自测 / 参数说明
            
          
          

            

              直行自测
              你照常手动往前开，它用 IMU 量这趟偏了多少 —— 不用看前轮、也不用自动驾驶
              

              
              
            

            
—

            
—

            

              前进/后退阈值不一样，这里可分开放。实际下发 电机PWM = 1500 ± 速度（出厂上限：前进 1680、后退 1330）。
              原厂驱动只给前进做起步补偿、不给倒车做，所以倒车会自动补一脚（前 0.3 秒再压低 ~80）帮它起步。改动会自动记住。
              车往左偏就把「直行微调」往正调、往右偏往负调（每次 0.5°），调到走直线为止；服务端存盘，重启也在。
            

            

              点一下 = 走「轻点」设定的时间（默认 150 ms，可设 0 = 松手立刻停）；按住 = 持续走（受安全锁限制）。
              跑 Nav2 时会和导航抢底盘，请先停导航。
