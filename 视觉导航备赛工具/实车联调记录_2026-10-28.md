## 重新启动只读调试

小车上的独立工作目录：

```sh
cd /home/deepbot/visual-race-trial-20261028-oHkBLD
bash ros2/vehicle_preview.sh status
bash ros2/vehicle_preview.sh start
```

`start` 会检查设备和端口是否被占用，仅启动只读预览；已经运行时不必重复启动。要停止本次预览可执行 `bash ros2/vehicle_preview.sh stop`。脚本只管理该目录记录的进程，不会修改原厂程序；进程与日志分别位于 `runtime/`。小车重启后需要重新执行 `start`，它不会自动开机运行。

在 Mac 上建立到小车只读桥的转发（当前黑豹校园网地址为 `10.123.40.48`，端口映射为 2225 → 小车 SSH）：

```sh
ssh -N -p 2225 -L 127.0.0.1:8770:127.0.0.1:8770 \
  -o 'HostKeyAlias=[10.51.166.90]:2225' deepbot@10.123.40.48
```

Mac 连接小车 `DEEPBOT-Vision` 热点、现场验证互联网正常后，可停止旧转发并改用直连：

```sh
ssh -N -L 127.0.0.1:8770:127.0.0.1:8770 \
  -o 'HostKeyAlias=[10.51.166.90]:2225' deepbot@192.168.77.1
```

保持 SSH 窗口打开，在 Mac 的平台目录运行 `python3 server.py`，访问 http://127.0.0.1:8766/。刷新页面后，选择“摄像头 · 感知”或“视觉赛道”查看画面，选择“计时 · 自测记录”查看识别和计圈状态。SSH、ZeroTier 或热点地址发生变化时，需要重新检查连接。
